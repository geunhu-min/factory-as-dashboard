# 클레임 개인업무 대시보드

일일업무 / 주간업무 / 월간업무 클레임 처리를 위한 대시보드입니다.

- `docs/` — 프론트엔드(정적 HTML/JS)와 로컬 실행용 Node 서버. GitHub Pages가 이 폴더를 그대로 서비스합니다.
- `gas/` — Google Apps Script 백엔드 모음. 각 파일은 특정 스프레드시트에 바인딩된 별도의 웹 앱이며, 파일 상단 주석에 배포 대상 스프레드시트와 배포 방법이 적혀 있습니다.

## 바로 열어보기 (GitHub Pages)

https://geunhu-min.github.io/factory-as-dashboard/

로컬 서버 없이 브라우저에서 바로 열립니다. 이 경우 연결 설정(웹 앱 URL)은 이 브라우저의 localStorage에만 저장됩니다 — 다른 사람/다른 브라우저와 공유되지 않고, 각자 자기 브라우저에 한 번씩 입력해두면 됩니다. "회수누적(CSV)" 탭은 로컬 서버의 CORS 우회 프록시가 없어서, 구글이 직접 크로스오리진 요청을 허용하지 않으면 이 방식에서는 안 될 수 있습니다.

## 로컬에서 실행 (여러 사람이 같은 서버에서 같은 설정 공유)

```
cd docs
node server.js
```

브라우저에서 `http://localhost:5175` 접속. 이 경우 연결 설정은 `docs/data/config.json`(이 저장소에는 포함 안 됨)에 저장되어, 같은 서버에 접속하는 모든 브라우저가 같은 값을 봅니다.

## GAS 배포

`gas/` 안의 각 파일을 해당 스프레드시트의 Apps Script 프로젝트에 붙여넣고 웹 앱으로 배포합니다. 자세한 내용은 각 파일 상단의 주석을 참고하세요.
