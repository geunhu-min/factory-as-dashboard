# 클레임 개인업무 대시보드

일일업무 / 주간업무 / 월간업무 클레임 처리를 위한 대시보드입니다.

- `factory-as-sample/` — 프론트엔드(정적 HTML/JS)와 로컬 실행용 Node 서버
- `gas/` — Google Apps Script 백엔드 모음. 각 파일은 특정 스프레드시트에 바인딩된 별도의 웹 앱이며, 파일 상단 주석에 배포 대상 스프레드시트와 배포 방법이 적혀 있습니다.

## 실행 방법

```
cd factory-as-sample
node server.js
```

브라우저에서 `http://localhost:5175` 접속. 첫 실행 시 각 기능의 "연결" 설정에 해당 GAS 웹 앱 URL을 입력/저장해야 합니다(URL은 로컬에만 저장되며 이 저장소에는 포함되지 않습니다).

## GAS 배포

`gas/` 안의 각 파일을 해당 스프레드시트의 Apps Script 프로젝트에 붙여넣고 웹 앱으로 배포합니다. 자세한 내용은 각 파일 상단의 주석을 참고하세요.
